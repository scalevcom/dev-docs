Once connected, your AI assistant will have access to all Scalev API endpoints as MCP tools. The tools are organized by resource categories:

### Bundles Management

* Create, retrieve, update, delete, and list bundles
* Manage bundle price options (BPOs)
* Handle bundle follow-up chats
* Associate bundles with partners
* Show bundle relations and sharing settings

### Orders & Transactions

* **Core Operations**: Create, retrieve, update, list, and delete orders
* **Shipment Management**: Generate AWB, cancel AWB, update shipment details and receipts
* **Payment Processing**: Create payment intents, check payment/settlement status
* **Order Communications**: Manage order chats and email notifications
* **Advanced Features**: Duplicate orders, bulk upload via CSV, change order status, mark as not spam
* **Analytics**: Order statistics and purchase event triggers
* **Digital Delivery**: Send LMS access and digital product downloads

### Products Catalog

* Create, retrieve, update, delete, and list products
* Manage product variants and digital files
* Handle product follow-up chats
* Associate products with partners
* Manage product taxonomies
* Update product sharing settings

### Stores Configuration

* Create, retrieve, update, delete, and list stores
* Associate stores with products, bundles, and bundle price options
* Configure payment methods and courier services
* Manage store admins and advertisers
* Handle store follow-up chats
* View store relations and pages

### Shipping & Logistics

* Calculate shipping costs based on courier services
* Get shipping estimates for different routes
* Search warehouses based on location and availability

### Business Settings

* Retrieve enabled e-payment methods for businesses
* Manage location data with search and pagination

<br />

This list will be updated regularly as Scalev decides to add more tools or deprecate some tools.
